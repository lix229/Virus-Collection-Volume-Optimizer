# Streamlit Optimizer UI Mockups

These are static, review-only design mockups for the Virus Collection Volume Optimizer. They do not change the production Streamlit app.

Open `optimizer_ui_mockups.html` in a browser to review four directions:

1. Guided Workbench
2. Guided Workbench + Stability Preview
3. Decision Brief
4. Operator Console

Rendered screenshots are also available:

- `screenshots/optimizer_ui_mockups_desktop.png`
- `screenshots/optimizer_ui_mockups_mobile.png`

The mockups are based on:

- Streamlit layout guidance for sidebars, columns, tabs, expanders, and containers.
- NN/g usability heuristics: visible system status, error prevention, recognition over recall, and aesthetic/minimalist design.
- Material guidance for data tables, responsive structure, color/contrast, and clear hierarchy.
